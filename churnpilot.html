ChurnPilot scans for credit card and bank account offers and surfaces an estimated profit-per-action — a scaffold built to extend with real scrapers and affiliate API integrations, backed by a live financial news feed.

What It Does

◉

Offer Scanner

Scans bank account and credit card offers and ranks them by estimated profit per action.

▲

Profit Estimation

Estimates payout and value per offer so you can prioritize the highest-return moves first.

☐

Live News Feed

Integrates a live news feed for bank and credit card offers to keep opportunities current.

◇

Extensible Engine

Designed as a scaffold — plug in affiliate partner APIs or compliant scrapers to go live.

▣

Mock-Data Ready

Ships with sample offers so the full flow runs instantly, with a clean path to real data.

⚑

Tested API

Pytest-covered API endpoints with a minimal, refreshable frontend UI.

Roadmap

  • Affiliate integrations — replace mock data with partner APIs and compliant sourcing.
  • Auth & rate-limiting — user accounts, persistence, and scheduled scanning.
  • Data enrichment — estimate conversion rates and payouts with historical tracking and A/B testing.
  • Attribution — track which offers convert to refine the profit model over time.

Quick Start

# create and activate a venv
python3 -m venv .venv
source .venv/bin/activate

# install dependencies and run
pip install -r requirements.txt
python app.py

# open http://127.0.0.1:5000

Responsible By Design

Scraping some sites can violate terms of service. ChurnPilot prefers official APIs and partner/affiliate programs, and respects robots.txt and partner terms — with legal guidance recommended before any production sourcing.
