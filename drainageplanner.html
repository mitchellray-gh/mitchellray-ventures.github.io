What It Does

▲

Topography & Slope

Interpolates elevation across survey points to model site topography, slope, and runoff paths.

◇

Runoff Estimation

SCS Curve Number and Rational method helpers estimate stormwater volume for right-sized systems.

◎

Soil Intelligence

Soil classification with infiltration guidance drives drainage recommendations that fit the ground.

□

Drainage Elements

Auto-generates swales, French drains, and catch basins alongside rain gardens and bioswales.

⚑

Interactive Maps

Click-to-place survey points with react-leaflet, plus device GPS auto-location and elevation lookup.

▤

Print-Ready Reports

Generates HTML reports with material takeoffs, cost estimates, and step-by-step install plans.

Why It Matters

  • Faster site assessments for property owners and contractors.
  • Installation-ready output — material lists and step-by-step plans, not just diagrams.
  • Landscape-friendly options — rain gardens and bioswales alongside engineered drainage.
  • Mobile-first design with a collapsible sidebar and touch-friendly controls.
  • AI chat assistant for conversational help on landscaping and drainage projects.

Quick Start

# from project root
npm install

# install client dependencies + build the React frontend
npm run client:install
npm run build

# serves API + React app at http://localhost:3000
npm start
