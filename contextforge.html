Messy inputs in.
Optimized context out.

ContextForge is a micro-SaaS that ingests URLs, raw text, and GitHub files and forges them into clean, token-efficient Markdown context packs ready to paste into — or stream to — any large language model.

What It Does

◆

Multi-Source Ingestion

GitHub files, URL scrapes, raw text, and Notion (schema-ready) all flow into one pipeline.

▣

Optimized Packs

Outputs clean Markdown with a token count for precise budgeting against any model window.

⚿

Secure By Default

Every table is protected with Row Level Security — users only ever see their own data.

◎

OAuth Sign-In

GitHub and Google auth via Supabase, with sessions kept fresh on every request.

▲

Server-First

React Server Components and Server Actions throughout; client code only where needed.

□

SSRF Guarded

Accurate token counting and budget-aware packs, hardened against server-side request forgery.

Roadmap

  • Dashboard — list, create, and view context packs.
  • Generate-pack engine — GitHub / URL / raw text into optimized Markdown.
  • Token budgeting UI — pack against a target model window.
  • MCP export — Model Context Protocol via the official SDK.
  • Vitest coverage — unit tests for parsing and database logic.

Quick Start

# clone and install
git clone https://github.com/mitchellray-gh/ContextForge.git
cd ContextForge && npm install

# configure environment, then run
cp .env.example .env.local
npm run dev

# open http://localhost:3000
